## The Golden Rules (Non-Negotiable)

1. **Be different (at all costs)** — If it sounds like every other ad, kill it
2. **Write like you talk** — Conversational, not corporate
3. **Use stories** — People buy stories, not features
4. **Make your ads valuable** — Teach something, reveal something, give something
5. **Your ads shouldn't look like ads** — They should look like posts from a friend
6. **Short sentences** — 5–10 words or less per sentence
7. **Spark enough emotion to generate a share and click** — If nobody would share it, rewrite it

## Ad Structure Framework

Every ad has 3 components. Master each one.

### Component 1: Headline (The Scroll-Stopper)

**Purpose:** Stop the thumb. Get the click. That's it.

**Rules:**
- Max 40 characters for primary headline (Meta)
- Lead with a number, a bold claim, or a pattern interrupt
- Use creative symbols, icons, and emojis — not just standard emojis but Unicode symbols (⚡️ 🔥 ⚡ ◆ ✦ ★ etc.)
- Mix icon styles for visual variety and creativity
- Create contrast with separators: `|` pipes, `→` arrows, `—` em dashes
- ALL CAPS sparingly for emphasis on 1–2 key words
- Never be boring — boring = invisible

**Headline Formulas That Work:**

| Formula | Example |
|---|---|
| Feature \| Feature \| Feature | `All-in-One CRM \| Without Monthly Costs` |
| Discount + CTA + Urgency | `60% OFF \| SĀC BEZMAKSAS \| NENOKAVĒ` |
| Comparison shock | `€900/mo vs €99 once. Sales CRM.` |
| Steal/Blueprint angle | `Steal My €4M Playbook for High-Ticket Clients` |
| "Do This" command | `Do This Tonight If You Have A Coaching Business` |
| Curiosity + geography | `European €4M Formula for Flooding High-Ticket Leads` |
| Scale promise | `Scale to €20k/Month Using My Free Blueprint` |
| Symbol-heavy visual | `Universāls CRM \| 1 Cena \| ∞ Lietotāji` |
| Bold claim + parenthetical | `B2B Business Are Going Crazy About This Offer` |

**Headline Variety Checklist:**
When creating multiple headlines, use DIFFERENT angles:
- [ ] Price/discount angle
- [ ] Result/outcome angle
- [ ] Curiosity/intrigue angle
- [ ] Fear of missing out angle
- [ ] Social proof angle
- [ ] Comparison/contrast angle
- [ ] Command/imperative angle
- [ ] Story/quote angle

---

### Component 2: Description Line (Under the Headline)

**Purpose:** Support the headline. Add one layer of context or urgency.

**Rules:**
- 1 sentence max
- Reinforces or completes the headline's promise
- Can include a micro-CTA

**Examples:**
- "Secure your lifetime access today"
- "Izmēģini bezmaksas un rezervē 60% atlaidi"
- "Previously sold for €2,000+ — now free"

---

### Component 3: Primary Text (The Body Copy)

**Purpose:** Sell the click. Build enough desire to take action.

**Structure Options (pick one per ad):**

#### Structure A: Hook → Features List → Proof → CTA
Best for: Product/service offers, CRM, tools

```
[1-2 sentence hook — bold claim or question]

[What you're getting:]
✅ Feature 1
✅ Feature 2
✅ Feature 3
...

[Proof section:]
💰 [Big number]
⭐ [Reviews/clients]
🌍 [Geographic reach]

[CTA]
👉 Link
```

#### Structure B: Problem → Agitate → Solution → Proof → CTA
Best for: Service offers, consulting, done-for-you

```
[Paint the problem — 2-3 short sentences]

[Agitate — make it worse]

[Introduce the solution]

Our service:
☑️ Benefit 1
☑️ Benefit 2
☑️ Benefit 3

[Proof — client results with names and numbers]

[CTA]
👉 Link

Stay Sharp & Make a Move
```

#### Structure C: Story/Authority → System Reveal → Results → CTA
Best for: Course, blueprint, webinar, challenge offers

```
[Authority positioning — who you are, why listen]

[The insight — what most people get wrong]

[Your system — what you'll show them]

Over the past few years, this system has helped me:
→ [Result 1]
→ [Result 2]
→ [Result 3]

And it's the exact same system that has helped:
→ [Client name] [specific result]
→ [Client name] [specific result]
→ [Client name] [specific result]

👉 [CTA with link]

[Sign-off]
```

#### Structure D: Negative → Positive Flip → Offer → CTA
Best for: Challenge offers, transformation promises

```
Instead of [bad thing 1] or [bad thing 2]…

you get [good thing]. Fast.

No [objection 1].
No [objection 2].
Just [simple promise].

In [timeframe] you will get:
#1 → [Deliverable]
#2 → [Deliverable]
#3 → [Deliverable]

[CTA]

P.S. [proof line]
```

## Icon & Symbol System

**DO NOT just use basic emojis.** Mix these styles for visual variety:

### Checkmarks & Status
- ✅ ☑️ ✔️ → confirmed/included features
- ❌ → what they're currently doing wrong
- ◆ → premium bullet points

### Arrows & Flow
- → → client result arrows, flow indicators
- 👉 → CTA pointer
- 👇 → scroll/read-on pointer
- ⬇ → download/ticket pointer
- ⬇️ → strong downward CTA

### Numbers & Lists
- 1️⃣ 2️⃣ 3️⃣ → numbered steps
- #1 #2 #3 → hash-numbered items (more casual)

### Energy & Impact
- ⚡️ → explosive feature
- ⚡ → speed/power
- 🔥 → hot/trending
- 💥 → impact
- 🚀 → growth/launch

### Business & Money
- 💰 → revenue/money
- 💸 → money flowing/savings
- 📈 → growth
- 📉 → decline (use for problem framing)

### Trust & Proof
- ⭐ → reviews/ratings
- 🏆 → wins/achievements
- 🥇 → #1 positioning
- 🗞 → media mentions

### Categories & Organization
- 📌 → big/foundational features
- 📝 → planning/notes features
- 🏢 → business/company features
- 📅 → scheduling/calendar
- ⚙️ → technical/integration features
- 🇱🇻 → Latvia-specific

### Gifting & Bonuses
- 🎁 → bonus items
- 🎟 → tickets
- 🎯 → guarantees

### Warning & Urgency
- ⚠️ → warning/attention
- 🛑 → stop doing this
- 💀 → death/pain (dramatic problem framing)

**Mixing Rule:** Use 3–5 different icon styles per ad. Never use the same emoji for every bullet point — vary them to create visual interest and make each line feel distinct.

## Copy Rules

### Tone
- Direct, punchy, confident
- Never corporate, never fluffy
- Write like you're texting a business friend
- Casual but credible

### Language Level
- 3rd–5th grade reading level
- Short words over long words
- Active voice always
- "Get" not "Acquire." "Build" not "Construct." "Grow" not "Scale strategically."

### Sentence Structure
- 5–10 words per sentence max
- One idea per sentence
- Line breaks between every 1–2 sentences
- Let the copy breathe — white space sells

### Proof Integration
- ALWAYS include at least one proof element
- Name-drop real clients with real numbers
- Use specific numbers, never rounds: "€172,000" not "€170K"
- Social proof as throwaway lines, not bragging

### The "Feels Illegal" Test
Your best ads should make the reader think: "This offer is too good to be true." If they don't feel that — the offer isn't strong enough.

### Sign-Off
End body copy with one of:
- `Stay Sharp & Make a Move`
- `P.S. [proof/urgency line]`
- Both (P.S. first, then sign-off)

## Platform-Specific Notes

### Meta (Facebook/Instagram)
- Primary text: 125 chars visible before "See More" — front-load the hook
- Headline: 40 chars max
- Description: 30 chars max
- Write the first line to be SO compelling they tap "See More"
- Long-form primary text (200–500 words) works when the copy is good
- Use line breaks aggressively — wall of text = death

### Google Ads
- Headlines: 30 chars each (up to 15)
- Descriptions: 90 chars each (up to 4)
- More keyword-driven, less emotional
- Still be direct and benefit-focused

### LinkedIn
- More professional but still punchy
- Can be slightly longer-form
- Authority and proof matter more here
- No flashy emojis — use → ✅ sparingly

### TikTok
- Ultra-casual, meme-adjacent
- Short — attention span is 2 seconds
- Hook in first line or lose them
- "POV:" and "Nobody:" formats work

## Variation Strategy

When creating ad sets, always provide:
- **Minimum 3 headline variations** per angle
- **Minimum 2 primary text variations** per structure
- **Mix structures** — don't give 5 versions of the same format
- **Mix angles** — pain, gain, curiosity, proof, urgency, story
- **Mix lengths** — some short & punchy, some long & story-driven

### Testing Priority
1. Test headlines first (biggest impact on CTR)
2. Then test hooks (first line of primary text)
3. Then test body structure
4. Then test CTAs

## Client Ad Variations (Onboarding Engine Format)

When writing ads for a **new client** via the Client Onboarding Engine, create **5 ad variations** — each from a different angle. This is the standard deliverable format.

### The 5 Ad Angles

| Ad # | Angle | What It Does |
|---|---|---|
| 1 | **Pain Point → Solution** | Opens with the target audience's biggest frustration, then introduces the client's service as the fix. Story-based, longer primary text. |
| 2 | **Social Proof / Results** | Leads with numbers, testimonials, or credentials. Trust-first — proof they can deliver. |
| 3 | **Direct Offer** | Short, punchy, straight to the CTA. No story — just "here's what you get, here's what to do." |
| 4 | **Education / "Did You Know?"** | Value-first — teaches something, positions the client as the expert. Soft sell at the end. |
| 5 | **Objection Killer** | Addresses the #1 objection head-on (price, trust, time, "I've tried this before") and flips it. |

### Per-Ad Deliverables

Every ad variation must include these 4 elements:

| Element | Spec |
|---|---|
| **Headline** | Max 40 characters (for Meta). Scroll-stopping. Uses formulas from the headline section above. |
| **Description** | Max 125 characters. One sentence that supports the headline or adds urgency. |
| **Primary Text** | 150–300 words. The full ad body copy. Follows one of the Structure frameworks (A/B/C/D) from above. |
| **CTA Button** | Recommend one: `Learn More` / `Sign Up` / `Book Now` / `Get Offer` / `Send Message` |

### Client Ad Copy Rules (Non-Negotiable)

These apply on top of the standard Golden Rules:

1. **Use the client's language** — mirror words from their form submission, not marketing jargon
2. **Include at least 1 trust signal per ad** — from the client's form field 9 (why clients trust them)
3. **Be specific to their niche** — mention their industry, audience, and location where relevant
4. **Use their proof points** — years in business, clients served, specific results they've achieved
5. **Write for their target audience** — the ad speaks to the client's ICP, not to the client themselves
6. **Match their tone** — if the client is corporate (law firm), dial back the casual. If they're trades (plumber), keep it blue-collar

## Anti-AI Slop Rules (MANDATORY)

> Full rules: `.claude/skills/7-anti-ai-slop/SKILL.md` — read and follow for ALL ad copy.

**Before writing any ad copy, internalize these:**

1. **No banned AI phrases in ad copy.** Never use: "delve into", "leverage", "synergies", "navigate", "empower", "unlock potential", "seamless", "robust", "cutting-edge", "game-changer", "revolutionize", "elevate", "harness", "foster", "landscape", "holistic". Use plain words: "use", "help", "build", "grow", "get", "fix".
2. **No transition word openers.** Never start a sentence with "Moreover", "Furthermore", "Additionally", "That said", "Importantly". Just say the next thing.
3. **No "Bold: colon: explanation" bullet lists.** Not "Clarity: Ensure your message is clear." Write real sentences with real information.
4. **No impressive-sounding sentences that say nothing.** If a line could apply to any business, it's filler. Cut it. Be specific to THIS offer, THIS audience, THIS result.
5. **Read it out loud.** If it sounds like a marketing robot, rewrite it. If you wouldn't say it to a friend, don't put it in an ad.
6. **Every paragraph must have a clear point.** If you read a paragraph and can't summarize what it said in plain English — delete it.
7. **No neat bow conclusions.** "At the end of the day, it comes down to execution" = filler. End with a specific CTA or proof point.
