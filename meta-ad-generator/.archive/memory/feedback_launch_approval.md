name: Wait for launch approval
description: Always wait for explicit user approval before uploading/launching ads to Meta — never auto-launch
type: feedback
---

Always wait for explicit user confirmation before uploading ads to Meta or any ad platform.

**Why:** User wants to review and potentially make changes before ads go live. Launching without approval risks sending duplicates or unfinished versions.

**How to apply:** After creating ad creatives (images + copy), present them to the user and explicitly ask "Palaižam Meta?" or similar. Only proceed with API calls to create adsets/ads after the user says yes.
