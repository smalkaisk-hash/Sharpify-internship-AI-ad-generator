# Notification Card (iPhone-style "Jauns pieteikums")

**Status:** Core proof element used inside sticker-card and other formats.

**When to use:** Any ad where the message is "leads come in automatically" — the notification shows concrete example of what a lead looks like arriving on the client's phone.

## Visual spec

- White card, iPhone notification style
- Slight rotation (+2.4° when paired with sticker card's -1.4° negative rotation)
- Top bar: app name (e.g., "MP Risinājums" or "Sharpify") + timestamp ("now")
- Title: niche-specific pieteikums label
- Body: concrete example of what the lead requested

## Niche-specific examples

Use real-sounding specifics, not generic "new lead":

| Niche | Notification body |
|---|---|
| Auto service | `TA + bremžu maiņa · Audi A6 · Rīga` |
| Beauty | `Gēla manikīrs · Elīna K. · Rīga` |
| Construction foundations | `Pamatu liešana · 180m² · Ķekava` |
| Roofing | `Jumta remonts · Jumata nomaiņa · Mārupe` |
| Tiling | `Vannas flīzēšana · 12m² · Liepāja` |
| IT | `IT konsultācija · Mazais bizness · Jelgava` |
| Solar panels | `Saules paneļi · 5kW sistēma · Ogre` |
| Fences | `Žogs ap māju · 80m · Salaspils` |

## Correct LV abbreviations

- Auto: **"TA"** (Tehniskā apskate), NOT "TO"
- Prefer **"bremžu maiņa"** over "bremžu nomaiņa" — shorter, more colloquial

## Why it works

Turns abstract "AI automation" or "lead generation system" into a concrete, visual, relatable moment. Same mechanism as real push notifications the viewer sees every day — cognitive shortcut to "this is real."
