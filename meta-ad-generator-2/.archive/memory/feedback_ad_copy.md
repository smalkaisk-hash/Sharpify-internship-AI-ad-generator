---
name: Ad copy variation rules
description: Never use identical text across multiple ads in the same set — each ad needs unique headlines and copy
type: feedback
---

Never use the same headline or text on two different ads in the same campaign/adset. Each ad must have unique copy.

**Why:** The user provides example text as a directional "hook" concept, not as literal copy to duplicate. Repeating text looks lazy and defeats the purpose of A/B testing different angles.

**How to apply:** When creating multiple ad variants, always write distinct headlines and body text for each. Use the user's example as inspiration for the tone/direction, then create variations that test different angles, emotions, or value props.
